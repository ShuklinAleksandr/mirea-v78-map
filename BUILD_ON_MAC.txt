Главная А2 → А3 принята пользователем. Нижние спуски А2 → А1 и
А1 → цоколь должны идти с двух боков к центру, с малой площадкой.
Это не препятствует тестовой компиляции. Не считайте успешную сборку
подтверждением правильности лестниц или готовности к предрелизу.

Сборка Android и веб-версии на Mac описана в docs/MOBILE.md.
Для сайта установите Node.js 24 и выполните npm ci и npm run build.
Для Android дополнительно установите JDK 21+, SDK API 36,
Build Tools 35.0.0 и platform-tools. Выполните npm run mobile:doctor,
npm run mobile:build:android и npm run mobile:check.
Веб-сборка находится в dist/, APK — в android/app/build/outputs/apk/debug/.
