# Карта МИРЭА · Вернадского, 78

Интерактивная 2D/3D-карта РТУ МИРЭА: поиск аудиторий и полезных мест, маршруты между этажами, веб-версия для телефонов (включая Safari на iOS) и компьютеров, Android-приложение на Capacitor.

**[Документация](docs/README.md) · [Интерфейс и обновление](docs/INTERFACE_COMPARISON.md) · [Участие в разработке](CONTRIBUTING.md) · [Android и iOS](docs/MOBILE.md) · [Вопросы по карте](ВОПРОСЫ_ПО_КАРТЕ.md)**

Основной приоритет — Android и мобильный веб. Настольный браузер поддерживается как дополнительный способ работы с картой.

## Текущая версия

В приложении оставлен **один интерфейс**: компактное ведение по маршруту, поиск с учётом корпуса и ближайших мест, настройки качества. Переключателя вариантов и названий «Классика/Новая» больше нет. Старые ссылки с `?interface=classic` и `?interface=next` открывают то же приложение.

Актуальные исходники — ветка **`main`**. ## Экран карты и этажи

На телефоне кнопки возврата ко всем корпусам, «Снаружи», «Внутри» и 2D/3D размещены компактно сверху. Основные действия представлены значками с доступными названиями и областями нажатия от 44 px. Кнопка со значком слоёв и номером открывает выбор этажей; в диалоге также доступны аудитории корпуса. В горизонтальном режиме поиск и маршрут располагаются сбоку, оставляя середину карты свободной.

Номер физического этажа учитывает корпус в **уже открытом плане**. Он может уточняться по однозначному положению центра карты внутри корпуса, надёжной текущей точке или существующему участку маршрута. На границе корпусов и в неоднозначном проходе сохраняется последний подтверждённый контекст. Это не автоматический переход на другой план и не измерение высоты: **GPS не определяет этаж**, а прохождение лестницы по-прежнему подтверждает пользователь.

## Жесты на телефоне

- Один палец перемещает карту.
- Сведение и разведение двух пальцев меняет масштаб.
- Разворот двух пальцев вокруг друг друга поворачивает карту в 2D и 3D. Движение пальцев вместе перемещает карту.
- Можно одновременно приближать, поворачивать и перемещать карту, не отпуская пальцы. Точка карты под центром пальцев остаётся под ними. Наклон 3D при этих жестах не меняется.
- Короткое неподвижное нажатие открывает место. Перетаскивание или щипок, начатые на подписи, управляют картой и не открывают карточку.

## Возможности

- Плоский 2D-план и объёмный 3D-вид кампуса, корпусов и этажей. Переход «Снаружи → Внутри» сохраняет масштаб и показывает общий план вокруг выбранного корпуса. При переключении 2D/3D сохраняется выбранное направление карты.
- На карте показывается один выбранный этаж; режима «Все этажи» нет. В маршруте доступны отдельные этажи и лестничные переходы.
- Качество по умолчанию — «Баланс»; лимит кадров настраивается отдельно. Экономный режим снижает разрешение и число деталей. Динамические 3D-тени отключены во всех вариантах качества; освещение формы сохранено. Неподвижная карта не требует новых кадров.
- Панель поиска разворачивается на доступную высоту с учётом клавиатуры и системных кнопок; в горизонтальном положении расположена сбоку. Кнопки режимов становятся значками с областью нажатия от 44 px; поиск сворачивается в отдельную кнопку. При вводе активное поле и прокручиваемые подсказки занимают доступную высоту над клавиатурой. Выбор корпуса или «Общего вида» на телефоне сворачивает её и открывает карту.
- Поиск аудиторий, туалетов, мест питания и других сервисов; подписи корпуса, этажа и известного ориентира. У выбранного корпуса доступен список аудиторий по этажам.
- Маршруты по существующему графу проходов, шаги маршрута, кнопка «От меня», избранное и ссылки на места.
- Системная геопозиция, ручное уточнение точки и следование камеры; поворот по компасу, когда доступны надёжные показания.
- Режим «Чистая карта», отдельные настройки подписей и окружающих зданий.
- Встроенные ресурсы карты для работы Android/iOS-приложений без сайта. Веб-версия загружает данные с сервера.

При первом запуске обновления прежнее сохранённое качество «Автоматически» однократно заменяется на «Баланс», если это сохранение ещё не проходило перенос настройки качества. Старый код записывал `auto` и без действий пользователя, поэтому отличить прежний явный выбор от значения по умолчанию нельзя. «Экономия заряда» и «Высокое», другие настройки и избранное сохраняются. После обновления можно снова выбрать «Автоматически» — этот выбор больше не сбрасывается.

## Запуск на компьютере: Windows, macOS и Linux

Нужны **Node.js 24** (минимум 22.12), npm и Git. Для полного набора тестов нужен также Python 3, доступный командой `python3`. Xcode и Android SDK для браузерной версии не требуются.

В Terminal на Mac/Linux или PowerShell на Windows:

```sh
git clone https://github.com/ShuklinAleksandr/mirea-v78-map.git
cd mirea-v78-map
npm ci
npm run dev
```

Можно скачать ZIP нужной ветки через GitHub, распаковать и выполнить две последние команды в папке с `package.json`. Зависимости устанавливаются заново на каждом компьютере; переносить `node_modules` не нужно. Если установлен nvm, команда `nvm use` выберет версию из `.nvmrc`.

Откройте адрес, который напечатает сервер, обычно `http://localhost:5173`. Параметр выбора интерфейса не нужен.

Если сервер выбрал другой порт, замените `5173` фактическим. Терминал должен оставаться открытым. Остановка — `Ctrl+C` или `npm run stop`.

## Веб-версия на телефоне, включая iPhone

**[Открыть карту в Safari или другом браузере](https://shuklinaleksandr.github.io/mirea-v78-map/)**. Для передачи другому человеку достаточно этой ссылки: компьютер автора и локальный сервер не нужны.

На iPhone: откройте ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить» (при наличии включите «Открыть как веб-приложение»). Это веб-версия, не IPA или TestFlight. Для загрузки карты нужен интернет; автономный холодный запуск сайта пока не реализован.

Одна и та же веб-сборка открывается в мобильном браузере, в том числе Safari на iPhone. Для проверки геопозиции и компаса нужен **HTTPS** и разрешение пользователя; доступность датчиков зависит от браузера и устройства. GPS не определяет этаж.

Для просмотра карты по локальной сети:

```sh
npm exec -- vite --host
```

Подключите телефон к той же сети и откройте адрес `Network` из терминала. Обычный `http://` по локальному IP подходит для просмотра карты, но не для полноценной проверки геопозиции и датчиков. `localhost` на телефоне относится к самому телефону, а не к компьютеру. Для таких испытаний используйте HTTPS-публикацию. Установка через App Store или TestFlight для просмотра сайта не нужна.

## Веб-сборка и публикация

```sh
npm run build
npm run preview
```

Готовые файлы находятся в `dist/`. Публикуется всё содержимое этой папки, включая `assets/` и `data/`. Открытие `index.html` через `file://` не заменяет запуск через веб-сервер.

По умолчанию сайт собирается для корня `/`. Для GitHub Pages по пути репозитория на Mac/Linux:

```sh
BUILD_BASE=/mirea-v78-map/ npm run build
```

Эквивалент для PowerShell и подробности — в [инструкции публикации](docs/INTERFACE_COMPARISON.md#публикация-одной-веб-сборки). Для Android и сайта используется один исходный проект. Перед нативной сборкой `BUILD_BASE` должен быть не задан либо равен `/`.

## Сборка Android и iOS

[Полная мобильная инструкция](docs/MOBILE.md) описывает установку окружения и отдельную Android-сборку на Windows/Linux. На Mac для общей сборки нужны полный **Xcode 26+**, **JDK 21+**, Android SDK **API 36**, **Build Tools 35.0.0** и platform-tools. В проекте используется AGP **8.13.0**.

После `npm ci`:

```sh
npm run mobile:doctor
npm run mobile:build:macos
```

Команда выполняет проверки, веб-сборку, синхронизацию и настоящие нативные компиляции. Ожидаемые выходные файлы после успешной сборки:

- Android: `android/app/build/outputs/apk/debug/app-debug.apk`.
- iOS Simulator: `.native-build/ios/Build/Products/Debug-iphonesimulator/App.app`.
- Журналы и состояния: `.native-build/macos/<время-запуска>/`.

Для установки собственного APK по USB:

```sh
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

Для сборки iOS на другом Mac передаётся **весь репозиторий**, включая `ios/App/App.xcodeproj`, Swift Package Manager и нативные плагины. На Mac с Node 24 и полным Xcode 26+:

```sh
npm ci
npm test
npm run mobile:sync
npm run mobile:check
open ios/App/App.xcodeproj
```

В Xcode выберите схему **App**, устройство или Simulator и нажмите Run. Для настоящего iPhone нужны Team владельца и development-подпись: [инструкция Xcode → iPhone](XCODE_IPHONE.md). **Simulator App не устанавливается на iPhone и не подходит для TestFlight.** Веб-версия для Safari и нативное iOS-приложение — разные способы запуска.

## Известные ограничения

- GPS внутри здания и геопривязка приблизительны. Автоматического определения этажа и готовой Wi-Fi-радиокарты нет. Ручное уточнение не превращает GPS в точную навигацию внутри помещения.
- При слабой, устаревшей или неоднозначной геопозиции автоматическое ведение приостанавливается. Переход между этажами подтверждает пользователь.
- Связность маршрутов неполна. Обновление интерфейса не добавляет проходов через стены; подтверждённого плана цоколя нет. Высоты и часть геометрии приблизительны.
- Производительность, датчики, клавиатура и системные отступы требуют проверки на настоящих телефонах. Успешные тесты и компиляция не подтверждают точность здания или удобство всех устройств.
- Подписанная сборка для настоящего iPhone и TestFlight требует отдельной подготовки владельцем. Исторические Simulator-сборки не являются её заменой.
