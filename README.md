# Карта МИРЭА · Вернадского, 78

Интерактивная 2D/3D-карта РТУ МИРЭА: поиск аудиторий и полезных мест, маршруты между этажами и мобильные приложения на Capacitor.

**[Документация](docs/README.md) · [Участие в разработке](CONTRIBUTING.md) · [Android и iOS](docs/MOBILE.md) · [Вопросы по карте](ВОПРОСЫ_ПО_КАРТЕ.md)**

## Возможности

- Обзор кампуса, корпусов и этажей в 2D и 3D.
- Поиск аудиторий, туалетов, мест питания и других сервисов; ближайшие варианты с корпусом, этажом или известным ориентиром.
- Маршруты по существующим проходам, компактные шаги и кнопка «От меня».
- Системная геопозиция, ручное уточнение точки и следование камеры.
- Направление телефона при доступном надёжном компасе.
- Android-инструмент Wi-Fi-замеров: точное место на плане и локальный экспорт JSON.
- Ресурсы карты внутри Android/iOS-приложений для работы без сайта.

## Быстрый старт

Нужны **Node.js 24** (минимум 22.12), npm и Git. Для полного набора тестов нужен также Python 3. В каталоге клонированного репозитория:

```sh
npm ci
npm run dev
```

Откройте локальный адрес, который напечатает сервер. Чтобы остановить сервер, нажмите `Ctrl+C` или выполните `npm run stop`.

Если установлен nvm, выбрать версию Node можно командой `nvm use`: версия указана в `.nvmrc`. Зависимости устанавливаются отдельно на каждом компьютере.

## Запуск на ПК: Windows, macOS и Linux

1. Установите Node.js 24 и Git.
2. Склонируйте репозиторий через GitHub Desktop или командой ниже. Замените `OWNER` на владельца репозитория.

```sh
git clone https://github.com/OWNER/mirea-v78-map.git
cd mirea-v78-map
npm ci
npm run dev
```

Команды одинаковы в Terminal на Mac/Linux и PowerShell на Windows. Вместо клонирования можно скачать Code → Download ZIP, распаковать и открыть Terminal/PowerShell в папке с `package.json`.

Примеры перехода в папку Downloads:

```powershell
# Windows PowerShell — замените путь своим
cd "$env:USERPROFILE\Downloads\mirea-v78-map"
npm ci
npm run dev
```

```sh
# macOS/Linux — замените путь своим
cd ~/Downloads/mirea-v78-map
npm ci
npm run dev
```

Откройте в браузере адрес из терминала, обычно `http://localhost:5173`. Терминал с сервером должен оставаться открытым. Для просмотра production-версии: `npm run build`, затем `npm run preview`. Для полного `npm run check` проверьте `python3 --version`: тесты вызывают именно эту команду. Python 3 должен быть доступен в PATH; Xcode и Android SDK для запуска карты на ПК не нужны.

## Установка на Android

В полном архиве файл находится в `release-assets/android/MIREA-V78-debug.apk`. После загрузки владельцем откройте **Releases** этого GitHub-репозитория, скачайте APK на Android и разрешите установку из выбранного браузера или файлового менеджера. Это отладочная сборка для испытаний.

При установленном Android SDK можно установить APK по USB:

```sh
adb install -r release-assets/android/MIREA-V78-debug.apk
```

Папка `release-assets/` исключена из Git. Владелец прикрепляет APK и контрольные суммы к GitHub Release; исходники загружаются обычным commit. Если APK не прикреплён, соберите его по [мобильной инструкции](docs/MOBILE.md).

Размер переданного APK: **53 915 300 байт**. SHA-256:

```text

```

## Мобильные приложения

Для общей сборки на Mac нужны полный **Xcode 26+**, **JDK 21+**, Android SDK **API 36**, **Build Tools 35.0.0** и platform-tools. AGP в проекте — **8.13.0**.

```sh
npm run mobile:doctor
npm run mobile:build:macos
```

Результаты:

- Android: `android/app/build/outputs/apk/debug/app-debug.apk`.
- iOS Simulator: `.native-build/ios/Build/Products/Debug-iphonesimulator/App.app`.

Для iOS передаётся **весь этот репозиторий**, включая `ios/App/App.xcodeproj`, Swift Package Manager и нативные плагины. На другом Mac с Node 24 и полным Xcode 26+:

```sh
npm ci
npm test
npm run mobile:sync
npm run mobile:check
open ios/App/App.xcodeproj
```

В Xcode выберите схему **App**, своё устройство или Simulator и нажмите Run. Для настоящего iPhone требуется отдельная development-подпись и Team владельца: **[инструкция Xcode → iPhone](XCODE_IPHONE.md)**. Simulator App не устанавливается на iPhone. Готовая сборка Simulator из полного архива находится в `release-assets/ios/MIREA-V78-iOS-Simulator.zip`. На совместимом Mac можно распаковать её и установить в запущенный iOS Simulator:

```sh
unzip release-assets/ios/MIREA-V78-iOS-Simulator.zip -d /tmp/mirea-v78-simulator
xcrun simctl install booted /tmp/mirea-v78-simulator/App.app
```

Если архитектура другого Mac не подходит готовому App, соберите проект в Xcode. Порядок Android-сборки на Windows/Linux описан в [мобильной документации](docs/MOBILE.md).

## Известные ограничения

- GPS внутри здания и геопривязка приблизительны. Автоматического определения этажа и готовой Wi-Fi-радиокарты нет.
- Компас, точность позиционирования, память и батарея требуют испытаний на настоящих телефонах. У Android software-эмулятора отмечены графические артефакты.
- Связность маршрутов неполна. Нижние лестницы и часть геометрии требуют уточнения; подтверждённого плана цоколя нет.
- Подписанной сборки для iPhone и TestFlight пока нет. Успешная компиляция не доказывает архитектурную точность карты.
