КАРТА РТУ МИРЭА ИЗ NINJA MIREA 5.3.0

Откройте index.html двойным щелчком в браузере. Интернет и установка приложения не нужны.
Выберите площадку и этаж. Для поиска аудитории введите её номер.
Колёсико мыши меняет масштаб; перетаскивание перемещает карту.

Извлечены 4 площадки и 23 плана этажей:
- Москва, проспект Вернадского, 78: Этаж 0, Этаж 1, Этаж 2, Этаж 3, Этаж 4
- Москва, проспект Вернадского, 86: Этаж 0, Этаж 1, Этаж 2, Этаж 3, Этаж 4, Этаж 5, Этаж 6, Этаж 7
- Москва, улица Стромынка, 20: Этаж 1, Этаж 2, Этаж 3, Этаж 4
- Москва, улица Малая Пироговская, 1: Цоколь, 1 этаж, 2 этаж, 3 этаж, 4 этаж, 5 этаж

Состав:
- index.html — автономный просмотр всех карт с поиском и масштабированием.
- svg/ — отдельные векторные планы этажей с подписями из каталога помещений.
- original/ — все файлы раздела maps из APK без изменений, включая 15 исходных SVG, каталог помещений и данные навигации в JSON.
- inventory.json — список подготовленных SVG и их SHA-256.

Источник: предоставленный файл Ninja+Mirea_5.3.0_APKPure.xapk, внутри ninja.mirea.mireaapp.apk, папка assets/flutter_assets/packages/app_ui/assets/maps/.
Исходный XAPK не изменялся.
Геометрия подготовленных планов взята из поля floors[].svg; подписи — из rooms[]. Они добавлены для удобства просмотра. Лестницы на планах обозначены ↕.
Данные приложения содержат ссылки на Пульс РТУ МИРЭА и University App. Метаданные исходных файлов сохранены. Актуальность расположения и назначения помещений отдельно не проверялась.
