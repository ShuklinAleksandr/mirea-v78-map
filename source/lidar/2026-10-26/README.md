# Сканы лестниц Polycam, переданные 28 октября 2026

Исходные архивы пользователя содержат бинарные PLY с XYZ/RGB, без граней и без объявления единиц. Цвета не переносятся в карту. Привязка к номеру этажа не записана в PLY.

| Архив              | Локальный файл | Опознание по форме                                                                  |
| ------------------ | -------------- | ----------------------------------------------------------------------------------- |
| `26.10.2026.zip`   | `scan-1.ply`   | широкая главная лестница «штаны»                                                    |
| `26.10.2026 2.zip` | `scan-2.ply`   | стандартная межэтажная клетка с центральным проёмом, по описанию пользователя Г/В/Д |
| `26.10.2026 3.zip` | `scan-3.ply`   | нижняя лестница под «штанами», два спуска                                           |

`sources.json` сохраняет размеры и SHA-256 архивов/PLY. Исходные облака остаются локальными; они не нужны для обычной сборки приложения и не входят в APK/App. Для карты подготовлены отдельные компактные треугольные буферы в `src/data/stair-scan-meshes/`.

В переносимый архив `scripts/package-handoff.py` из этого каталога входят только этот README и `sources.json`. Исходные PLY с RGB и ZIP не включаются. Обработанные поверхности, скрипты и [актуальный отчёт о более ровных лестницах](../../../docs/STAIR_SMOOTH_2026-10-28.md) передаются вместе с кодом. [Первый отчёт](../../../docs/SCANNED_STAIRS_2026-10-28.md) сохраняет историю предыдущих сеток примерно по 6 000 треугольников. Для повторной обработки исходные PLY передаются отдельно с проверкой указанных SHA-256; для обычной сборки они не требуются.

Для повторения текущих поверхностей положите исходные PLY под указанными именами и из корня проекта выполните:

```sh
python3 scripts/polish-stair-scans.py --output-dir analysis/stairs-rebuild
```

Нужны Python, Open3D 0.19.0, NumPy и SciPy. Выходной каталог должен быть новым: существующие результаты не перезаписываются. Скрипт использует фильтры и оси `scripts/build-stair-scan-surfaces.py`, ограничивает перемещение выбранных точек величиной 0.06 исходной единицы, восстанавливает только поддержанные поверхности без заполнения дыр и выпускает до 24 000 треугольников на объект. Исходные PLY остаются неизменными. Результаты сохраняются отдельно для проверки перед заменой JSON приложения. Обзор исходников: `scripts/inspect-stair-scans.py`.

Исходная вертикаль — Z; в Three.js применяется правостороннее преобразование и отдельная привязка к плану. Метры и абсолютная геометрическая точность не установлены одним PLY: визуальная высота согласуется с существующим условным шагом этажей модели. Новые помещения, этажи и связи маршрутов из этих облаков автоматически не создаются.
