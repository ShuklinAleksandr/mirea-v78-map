Кнопка **«Все этажи · 3D»** в маршруте показывает несколько уровней на высотах модели, без искусственного разнесения. Переключатель этажей находится прямо на карте. В **2D** показывается один план. В режиме нескольких этажей верхние уровни прозрачны, активный выделен; известные лестницы и маршрут следуют маршам, неподтверждённые соединения отмечены условно. Высота уровня 3,6 м остаётся принятым допущением, а не обмером.

### iOS и Android

Нативные проекты используют одну карту и локальный комплект данных через Capacitor. Для запуска карты в приложении сервер разработки не требуется. В пакет входит только Вернадского, 78; набор обновляется целиком вместе с приложением. Текущий комплект данных — 82 файла, 57,4 МиБ. Это размер данных, а не установочного APK/IPA.

```sh
npm run mobile:sync
npm run mobile:build:ios
npm run mobile:build:android
npm run mobile:check
```

Android APK: `android/app/build/outputs/apk/debug/app-debug.apk`. iOS для симулятора: `.native-build/ios/Build/Products/Debug-iphonesimulator/App.app`. Для собственного iPhone требуется подпись вашей Development Team. [Настройка и границы проверки мобильных приложений](../docs/MOBILE.md).

Для переноса на другой Mac прочитайте `BUILD_ON_MAC.txt`; готовый промт для продолжения находится в `PROMPT_FOR_BUILD_PC.txt`. После установки зависимостей и окружения обе платформы собираются через `npm run mobile:build:macos`.

Локальное приложение на Three.js и Vite: внешний обзор В78, открытые планы этажей, выбор корпуса, поиск и карточки помещений. Данные зданий отделены от отображения. В исходном архиве сохранены **4 площадки, 23 плана уровней и 2659 каталожных объектов**; производственная сборка отбирает только В78. Число объектов включает входы и служебные зоны, а не только аудитории.

## Запуск

Нужны Node.js **22.12+**, npm и браузер с WebGL2. Из папки `3d-map`:

```sh
npm ci
npm run dev
```

Обычно карта открывается на **http://127.0.0.1:5173**. Точный адрес всегда напечатан в терминале после `Карта запущена:`. Повторный `npm run dev` останавливает предыдущий сервер разработки этого проекта и освобождает его порт, даже если раньше использовался другой порт. Если порт занят другим приложением, оно продолжит работать, а карта выберет следующий свободный порт. Можно указать предпочтительный порт: `npm run dev -- --port 5174`.

Для остановки нажмите **Ctrl+C** в терминале сервера. Команда **`npm run stop`** из другого терминала остановит оба сервера проекта — разработку и просмотр сборки. При закрытии терминала сервер также завершается. После аварийного завершения следующий запуск очищает оставшийся служебный сокет. Чужие процессы по номеру порта не завершаются.

Приложение загружает JSON через HTTP; открывать `index.html` двойным щелчком не нужно. `npm ci` достаточно выполнить при первой установке или обновлении зависимостей; перед переустановкой зависимостей остановите сервер через `npm run stop`.

```sh
npm test           # проверки данных, этажей, поиска и внешних объёмов
npm run check      # форматирование, все тесты и production-сборка
npm run build      # готовая сборка в dist/
npm run preview    # просмотр сборки, обычно http://127.0.0.1:4173
npm run stop       # остановить оба сервера проекта и освободить их порты
```

Для обычного запуска Python не требуется: подготовленные данные включены в проект. После установки зависимостей карта работает с локальными файлами; внешние ссылки на источники открываются отдельно. Размещать `dist/` нужно через HTTP-сервер в корне сайта: пути к данным начинаются с `/data/`.

## Управление

- Выберите корпус В78. «Кампус» показывает общий объём, «Этаж» — доступный уровень без закрывающей его крыши. Отдельные кнопки «2D» и «3D» меняют проекцию в любом из этих режимов.
- На сенсорном экране один палец перемещает карту. В 3D два пальца поворачивают вид и меняют масштаб; в 2D — перемещают и масштабируют без наклона. Мышью: левая кнопка вращает 3D-вид, правая перемещает, колесо меняет масштаб; в 2D левая кнопка перемещает карту.
- Нижнюю панель можно свайпом за верхнюю ручку развернуть, свернуть до компактного вида или убрать к нижнему краю. Длинный свайп вниз сразу освобождает карту; кнопка «Поиск и маршрут» возвращает панель. Выбор места или маршрута снова открывает нужную карточку.
- В результатах поиска и карточке указаны корпус и физический этаж, если они известны. Отдельная строка «Ориентир» указывает ближайшее подписанное помещение по существующим проходам; её корпус не приписывается самому объекту. Недостающие привязки перечислены в [списке для обследования](../docs/PLACE_LOCATION_GAPS_2026-10-20.md).
- Выберите этаж в панели. При выбранном корпусе отображается его физическая нумерация; без корпуса — общий уровень источника.
- Введите номер помещения, например `Г-207` или `207`. Выберите результат или нажмите Enter для первого совпадения — откроется нужная площадка и этаж. Клик по помещению показывает сведения и доступные ссылки между этажами.
- Кнопка общего вида возвращает обзор. Исходные SVG, фотографии и сведения о достоверности сохранены в репозитории; служебные кнопки удалены из пользовательского интерфейса.

## Пересборка исходных данных

Подготовленные цифровые оригиналы находятся в `source/maps/`. Для повторяемой конвертации достаточно этого каталога; родительские ZIP/XAPK и сеть не нужны.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r scripts/requirements-data.txt
python scripts/build-all.py
```

`python scripts/build-all.py --help` описывает параметры. Только явный режим `--from-archives` заново извлекает и проверяет три исходных файла ZIP/XAPK/HTML; они должны присутствовать вместе в родительской папке либо в `--archives-dir`.
