## Объём проверки

В браузерах проверялись обычные действия пользователя. Среди них выбор аудитории из поиска и с этажа, добавление в избранное, переключение темы, открытие присланного маршрута, выбор между двумя вариантами прохода, переход к следующему и предыдущему шагу, изменение точек и закрытие маршрута. При изменении размера окна также проверялись размеры полотна карты и пропорции камеры. Для проверенных состояний выполнен автоматический анализ доступности axe-core.

- Телефонные окна от 280×653 до 740×360, в том числе 320×480, 320×568, 360×640, 375×812, 512×300, 568×320 и 667×375. Крупный текст и уменьшение высоты окна при вводе проверены отдельно. Размеры указаны в CSS-пикселях.
- Планшеты и мониторы 768×1024, 820×1180, 1024×768, 1024×600, 1280×720, 1920×1080 и 2560×1080. В Chromium дополнительно проверены эти семь размеров при масштабе вкладки 100%, 125% и 200%, с мышью и сенсорным вводом. Ещё десять окон подобраны непосредственно у границ смены компоновки.
- В Chromium, Firefox и WebKit проверялись квадратное окно, изменение ориентации с открытой карточкой, поиск с клавиатуры и история переходов. Основной прогон выполнен в Chromium 159, Firefox 159 и WebKit 27.2. При проверке вырезов Chromium применял системные отступы до 42 пикселей. Для веб-сборки в подкаталоге `/mirea-v78-map/` отдельно проверены открытие ссылки и загрузка фонового построителя маршрута.
- Повторный запуск полного перебора обработал 3 405 870 направленных пар разных точек из 1 846. Для 597 954 пар построен точный путь, для 84 838 — частичный. Для 794 648 пар граф не содержит допустимого прохода, для 1 928 430 хотя бы одна точка не имеет подтверждённой привязки. Отдельно проверены 1 846 запросов из точки в неё же. В 1 316 756 сравнениях с независимой проверкой графа расхождений не обнаружено. Исходные данные и ограничения подробнее описаны в [аудите навигации](AUDIT_2026-11-20.md).

## Установка на Android

Итоговый APK установлен в эмулятор Android 16 (API 36) с Android System WebView 133. Воспроизводились экраны телефонов 720×1280 и 1080×2400, планшета 1600×2560, обе ориентации, системный шрифт 100%, 130% и 200%, жестовая и трёхкнопочная навигация. Здесь размеры указаны в пикселях экрана эмулятора.

Все восемь сценариев прошли на одном и том же APK. Проверены ввод непосредственно с экранной клавиатуры LatinIME, поиск, поворот во время ввода, открытие карточки, выбор обоих концов маршрута, переходы между шагами, список этажей, прокрутка настроек и системная кнопка «Назад». На широком планшете удалось прокрутить подсказки до последнего результата. На компактном горизонтальном телефоне даже с оставшимся окном 521×112 CSS-пикселей маршрут удалось построить и закрыть.

## Проверка сборки

Перед публикацией исходники извлекли из индекса Git в чистый каталог и выполнили `npm ci` и `npm run check`. В Chromium, Firefox и WebKit также проверили восстановление общей ссылки при сетевом сбое. После ответа HTTP 503 для обязательного каталога кнопка «Попробовать снова» открыла исходный маршрут. Отсутствующий каталог фотографий не помешал построению пути.

Прошли 976 автоматических тестов JavaScript, 5 тестов JVM и инструментальный тест Android `OfflineMapTest`. Собраны веб-версия, установочный debug APK, неподписанный release APK и Android App Bundle. Для debug APK проверена подпись v2 и совпадение всех 93 файлов веб-сборки. SHA-256 установочного APK — `211c11fb73e078eed7ddf903dc84ce66f3d6f490ee280a8413ce95d76c8d1686`. Android Lint выдал 30 предупреждений и 0 ошибок. В отчёте npm audit за этот запуск 0 известных уязвимостей.

```sh
npm ci
npm run check
npx playwright-core install chromium firefox webkit
npm run test:ui -- chromium firefox webkit
npm run mobile:build:android
npm run mobile:check
```

Логи этого прогона, снимки и таблица результатов по каждой паре лежат в `.native-build/audit-2026-11-20/ui/`. Браузерные размеры и эмулятор позволяют воспроизвести условия. Точность датчиков конкретного телефона и качество ведения при реальной ходьбе внутри здания требуют проверки на месте.
