# Два интерфейса в одном приложении — проверка 8 ноября 2026

Новый проход для ветки `feature/interface-comparison`, основанной на `feature/render-quality-and-stairs` (`b251513`). Это отдельный результат, не продолжение цифр старых отчётов. Карта, планы и граф маршрутов общие; новые геометрические соединения не добавлялись.

## Что получено

- Один Android Debug APK с переключателем **Классика / Новая**.
- Одна готовая веб-сборка с тем же переключателем для компьютеров и мобильных браузеров.
- Классика используется при первом запуске без явной ссылки. Вариант запоминается; ссылки `?interface=classic` и `?interface=next` открывают конкретный вариант.
- Переключение сохраняет выбранное место или начало/конец маршрута. Ведение и GPS-сессия перезапускаются. Настройки, избранное и локальные записи уточнений GPS разделены.

Описание изменений и инструкция запуска: [INTERFACE_COMPARISON.md](INTERFACE_COMPARISON.md).

## Проверка интерфейса

В браузере на собранной версии проверены переключение Классика → Новая → Классика с маршрутом Г-103-1 → Г-209, новая панель маршрута, полноэкранный список шагов, поиск «буфет» в поле «Куда», выбор физического этажа и ручные шаги при недоступной геопозиции. Проверены размеры 390×844 и 844×390. В журнале браузера ошибок не найдено.

При проверке исправлены отступ камеры от панели, отступ выбора этажа, положение панели в горизонтальном режиме, возврат автоматического FPS после адаптации и действие при неверно подтверждённом этаже GPS. В последнем случае предлагается уточнить точку, а не бесконечно менять только этаж просмотра.

Android: AVD `mirea-v78-api36`, `sdk_gphone64_arm64`, Android 16 / API 36, WebView `133.0.6943.137`, экран 1080×2400. Проверены установка APK, переключение вариантов с маршрутом, самостоятельное построение Г-103-1 → Г-209 без сети, полноэкранная панель с клавиатурой, Android «Назад», плоский 2D и горизонтальное ведение без GPS. Движение и координаты не имитировались.

После последнего исправления действия при несовпадении этажей окончательный APK повторно установлен через `adb install -r`: успешны холодный запуск без сети и Новая → Классика → Новая. Полные проверки раскладки выполнялись на предшествующей сборке с той же раскладкой. Время запуска Activity — 827 мс, это не время полной загрузки карты и не замер реального телефона. PSS основного процесса в одном снимке — 123 841 КиБ; это не суммарная память всех процессов WebView. Ошибок приложения при этих действиях не обнаружено.

Известное поведение: после принудительного завершения процесса приложение возвращается на главный экран А2, маршрут не восстанавливается. Переключение двух интерфейсов сохраняет его. Подробности и снимки — `android-qa.md` и `android-qa/` в каталоге материалов проверки.

## Журналы и ограничения

Все локальные материалы находятся в `.native-build/interface-comparison/`:

- `web.log` — полный проход проверок и веб-сборка;
- `android.log` — компиляция Android;
- `artifact-verification.json` — файлы и контрольные суммы APK;
- `apk-signature.log` — проверка подписи;
- `SHA256SUMS.txt` — суммы передаваемых APK и ZIP;
- `interface-switcher.jpg`, `web-classic.jpg`, `web-next.jpg` — снимки интерфейса.

Нативная iOS-сборка в этом проходе **не выполнялась**. Веб-код включён в общую сборку; работа на настоящем iPhone/Safari остаётся для испытаний команды. Наличие двух интерфейсов не подтверждает точность GPS внутри здания, автоматическое определение этажа, полноту маршрутов или архитектурную правильность лестниц. Полевые измерения плавности на слабых реальных телефонах не выполнялись.

Текущий APK имеет отладочную подпись и тот же идентификатор приложения: установка обновляет существующий экземпляр, а не создаёт второе приложение. Магазинный выпуск, TestFlight и подпись владельца для iPhone не готовились.
