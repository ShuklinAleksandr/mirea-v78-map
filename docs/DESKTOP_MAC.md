# Карта МИРЭА как обычное приложение Mac

Готовая версия не требует Node.js, терминала, открытого браузера или отдельного запуска сайта. Карта, поиск, маршруты, фотографии и поверхности лестниц находятся внутри приложения. Окно открывается в формате телефона и может менять размер.

## Установить готовое приложение

1. Скачайте **MIREA-V78-Mac-universal.dmg** из [тестового выпуска v0.4.0-test](https://github.com/ShuklinAleksandr/mirea-v78-map/releases/tag/v0.4.0-test).
2. Откройте DMG и перетащите «Карта МИРЭА.app» в «Программы» или свою папку `~/Applications`.
3. Открывайте «Карта МИРЭА» обычным двойным кликом.

Минимальная система — **macOS 14**. В одном приложении есть код для **Apple Silicon и Intel**; выбирать архитектуру не требуется. Фактический запуск этого прохода проверен на Apple Silicon / macOS 15.6.1. Запуск на Intel отдельно не проверялся.

Это локальная тестовая подпись, без Developer ID и нотарификации Apple. На другом Mac после скачивания система может потребовать дополнительное подтверждение или заблокировать приложение. Подготовка распространения без таких предупреждений требует подписи владельца и нотарификации; пароли и сертификаты в чат передавать не нужно. Не отключайте защиту macOS ради установки.

## Возможности

- Та же 2D/3D-карта В78, поиск, категории, избранное, этажи и маршруты.
- Сохранение выбранного вида и точек маршрута; проверено повторное открытие.
- Геопозиция через системную Core Location macOS, по явному включению пользователем. Точный этаж и место можно уточнять вручную. Радиозамеров Wi-Fi в приложении нет.
- Системное меню «Поделиться» и сохранение GPS-уточнений через диалог выбора файла.
- Обычные сочетания клавиш Mac для копирования и вставки. ⌘0 возвращает размер окна «как телефон».

Компьютер обычно не имеет компаса телефона; направление не выдумывается. Точность геопозиции зависит от macOS и доступных сигналов, GPS не подтверждает этаж. Реальная точность в здании и проходимость всех маршрутов этим проходом не проверены. Г-424-1 и остальные уточнения остаются в [списке вопросов](../ВОПРОСЫ_ПО_КАРТЕ.md).

## Собрать из исходников на Mac

Для разработчика нужны Node.js 24 и Xcode Command Line Tools с macOS SDK. После обычного `npm ci`:

```sh
npm run check
npm run desktop:mac:test
npm run desktop:mac
```

В `desktop-build/` появятся DMG, ZIP, `SHA256SUMS.txt` и отчёт `mac-build.json`. Само приложение компилируется из Swift/AppKit/WebKit; дополнительный браузерный движок не скачивается. Сборка включает только В78. Крупные исходные облака сканов для неё не нужны.

Для подписи временный `.app` создаётся вне синхронизируемой Documents: File Provider добавляет FinderInfo к `.app` в облачной папке, что мешает проверке подписи. Готовые DMG и ZIP сохраняются в проекте. Удаляются только упаковочные FinderInfo/ResourceFork у создаваемого файла; quarantine и системная защита не отключаются.

## Как устроена оболочка

`desktop/mac/` содержит окно, узкий мост к системным функциям и сервер файлов только на 127.0.0.1. Он запускается самим приложением, обслуживает только GET/HEAD из встроенного каталога и завершает работу вместе с приложением. Пользователь его отдельно не запускает. Для фотографий с кириллическими именами сохраняются точные имена и байты.

Навигация WebKit ограничена собственным локальным источником; мост принимает сообщения только главного фрейма из этого источника. Удалённые страницы внутри окна не открываются. Экспорт ограничен JSON В78 до 4 МиБ и файлом, выбранным пользователем в NSSavePanel. Core Location включается только по запросу и останавливается при скрытии/закрытии приложения.

## Windows

На Windows браузерная версия по-прежнему запускается из исходников:

```sh
npm ci
npm run dev
```

Откройте адрес из терминала. Отдельный Windows EXE в этом Mac-проходе не создавался.
