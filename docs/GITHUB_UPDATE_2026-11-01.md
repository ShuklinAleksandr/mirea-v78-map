```sh

npm run dev
```

Если у вас есть свои изменения, сначала сохраните их отдельным commit в своей ветке. Не используйте принудительный сброс, чтобы обновить карту.

## Открытые ограничения

Настоящий iPhone, development-подпись и TestFlight не проверены; Simulator App на iPhone не устанавливается. GPS в здании и абсолютная привязка карты приблизительны, этаж подтверждается человеком. Г-424-1 существует, но её внутренняя группа изолирована в исходном графе: для маршрута через Г-424 требуется положение двери. Подтверждённого плана цоколя нет. [Вопросы 073–074 и остальные уточнения](../ВОПРОСЫ_ПО_КАРТЕ.md) остаются в списке; публикация не подтверждает проходимость всех маршрутов.
