# Архив снятого Wi-Fi-инструмента

С 1 ноября 2026 инструмент не включается в приложение. Здесь сохранены старые модули и нативный сканер для истории и проверки формата прежних записей. Приложение их не импортирует, сканер не регистрируется и не компилируется в APK; Wi-Fi-разрешения удалены.

Исторические тесты `tests/wifi-survey*.test.mjs` продолжают проверять архивную реализацию. Чистая Java-политика ограничений сканирования и четыре JUnit-теста находятся только в Android test source set. Новые проверки отдельно подтверждают отсутствие функции в выпускаемом приложении.
